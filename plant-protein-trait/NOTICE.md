# Publication and attribution

This package was prepared for integration into the maintainer's existing repository. It does not assign a new license, invent an author list, claim a DOI, or supersede that repository's existing licensing terms. The maintainer should apply the repository's actual license and verify rights to the supplied original code before advertising unrestricted public reuse.

The original seven scripts were provided for audit and refactoring. Their hashes are retained in `docs/original_source_manifest.json`; their original private paths and contact details are not republished. The current single-protein implementation and behavior changes are described in `docs/AUDIT.md` and `CHANGELOG.md`.

Database data, external executables and model services have their own licenses, usage policies and citation requirements. Cite the actual tools/databases/releases used in the final scientific run. This package bundles none of their full databases or model weights.

For a paper, cite the actual authors, repository URL, released version and commit or an archival DOI once those exist. Do not invent a publication DOI or label the synthetic software tests as a biological validation study.
